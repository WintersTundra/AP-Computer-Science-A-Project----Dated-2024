# AP-Computer-Science-A-Project----Dated-2024
Home of my AP Computer Science A final project

Inspired by my experience with previous text adventures, this choose your own adventure games centers around keeping a very ordinary fishkeeper, with definitely no secrets to find. It is a very normal simulator.

Uses OOP
I took the user's ease of use into account while designing the program (For instance, having a select number menu rather than typing out the entire action request).
